## Deviations from the specs (and why)

1. **Parameter set follows the doc-12 registry**, not the feature files: no `fl12_main_mode` / `fl12_level` (the Wet bus is unity and always carries the fills; Dry-only main output is not offered), no `fl11_*` extras (Hit / CC events, velocity mode, hit length), no `fx06_slot` / priority / yield / grid, no `fx07_target`. The Options value `midiOutOffsetMs` (-100..+100) exists as `setMidiOutOffsetMs()` but has no Options row yet and is not persisted.
2. **F-M17 preserve rule not implemented**: the feature file keeps the mode across presets / Reset / Undo / file load. `wetSolo` is a performance id (Undo snapshots and Random already skip it) and no factory preset sets it; Reset-all and `.gapfill` load can still change it. The 5 ms crossfade is the existing 20 ms dry / wet smoother.
3. **F-L12 for AU**: the "Wet" bus is not declared for the Audio Unit wrapper (`PluginHostType::getPluginLoadedAs()` at construction) until `auval` + Logic pass, as specified; VST3, CLAP, Standalone and the test processor declare it. `-DGAPFILL_WET_BUS=OFF` removes it everywhere.
4. **F-L11 events**: gaps use `midiOutNote`, fills `midiOutNote + 1` (doc 12), not three separate notes and CC. Time-stamps are output-aligned only (no "Detection-early"). No MIDI CC output.
5. **F-L13 snap resolution**: the evaluation lands on the analysis hop grid (256 samples), so a snapped start is within 5.3 ms of the SC onset at 48 kHz. Fill Now is exempt from the gate and the snap.
6. **F-D03 SP-0 FFT size not lowered**: the bus cards allocate their STFT buffers once in `prepare()`, so a level change cannot shrink them without allocating on the audio thread. Lite switches the three spectral cards off instead (the saving that matters); Balanced keeps them at the full size. `SpectralSmear` (the Spectral fill algorithm) does run one order lower. Cloud grains are capped per voice; the density limit estimate is unchanged, so a low cap drops grains (counted) instead of thinning the density.
7. **F-D03 switch rule**: waiting for "no voice and no FX tail" could starve in dense material, so a pending change is applied after 1 s through the existing fade (`panicWet`: voices 4 ms, bus effects `fadeOut`).
8. **F-X06 is the doc-12 live design** (Avoid overlap / Alternate / Follow), not the feature file's rendezvous-hash ownership with slots, priority and yield. `Alternate` is the deterministic part (bar index x instance id order).

## Co-op: implemented vs documented

Implemented: registry (32 slots, atomics only, `SharedResourcePointer`, no pointers, trivially destructible), claim on first block with a group / release on Off, `releaseResources` and destructor, 2 s staleness, wall-clock and PPQ time domains (never mixed), the three modes, previous-block reads, footer text ("Co-op A: n other instances" / "Co-op: no other GapFill found").
Documented, not built: per-slot priority / yield, fixed slot numbers and rendezvous-hash ownership (reproducible regardless of processing order), duplicate-slot detection, group-wide scene recall, shared tempo / phrase estimate, per-fill claim messages in a seqlock ring, cross-track call and response. Known limits: hosts that sandbox plug-ins per process cannot see each other (inert, footer says so); Avoid overlap and Follow depend on processing order and timing and are not bit-reproducible; a muted track still counts as a member.
