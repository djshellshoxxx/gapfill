# Detailed harmonic controls —2026-10-31

The harmonic feature owns the seven HGEXT ParamInfo entries, Help section1700
and an Advanced-view PITCH SYNC launcher in CreativeExtra145. It opens a transient
448×224 panel; Off collapses its body and preserves all released hg* parameter
values. The two choice controls and five integer/float knobs use the shared
APVTS controls and MIDI-learn/reset/typed-entry menus. Explicit keyboard order
follows the layout, with accessible names, descriptions and standard focus
painting. Unknown key disables Key Snap with explanatory tooltip while retaining
its parameter value. The resolver uses published atomic auto/held key snapshots
and manual fallback, matching the existing context contract.

The panel owns a ComponentTranslator after its child controls so transient-window
labels, choices and titles refresh safely on a language change. Complete dynamic
readout templates use i18n::format on the message thread. Its4Hz text-only meter
reads hgState/hgF0/hgConfidence atomics:1Used,2UnvoicedFallback,3EpochFallback and
0idle. The Used line includes note, Hz and clarity; no source arrays/frame tracker
or audio-owned state is touched. Help documents source-dependent fallback, mono,
same-source Capture/Scan, cold-held enable, global-send blend and recipe semantics.

The12-byte optional metadata deliberately records the final decision, tracked
F0/clarity, interval set and voice count. A recipe is not a complete preset:
Lock/portable recall uses current captured PCM, Motion/Scatter/Tone/Snap, key and
FX Send, as existing recipes do. Full Event replay restores initial state and
parameter commands before reproducing the recorded decision. No independent
audio reproduction across changed source/settings is claimed.

Zero-send natural decisions use the explicit Bypassed4 outcome within the same
12-byte schema1 metadata: valid interval/voice selection, exactly zero F0/clarity,
no detector/epoch work and idle telemetry. This preserves detailed plain-Granular
dispatch for later recipe replay without mislabelling the source unvoiced or
re-enabling legacy Harmonic/Cloud through an absent sidecar. Incoming Used replay
retains its saved decision at zero current send. Unknown future outcomes continue
to invalidate only the optional harmonic metadata, never the16-byte base recipe.
