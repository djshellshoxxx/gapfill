macros, two global LFOs plus Energy, additive bipolar depths and a target table
whose appended entries differ from the persisted shipped entries.
`docs/dev/12-SPEC-FEATURES-INTEGRATION.md` F-M23 instead describes four macros,
four per-macro LFOs and the current 36-entry table. DECISIONS moves the work to
the decision stage but does not authorize rewriting persistent target indices.
The first-36 repair is approved and implemented as a compatible versioned slice.
An eight-macro/Energy extension requires reconciliation and append-only new
indices/IDs; it is not silently waived or claimed complete by this repair.

regressions ran: 48 passed, one completeness test failed with 13 findings
because this isolated worktree has the parent FL20 parameter registry but not
