# N-FX2 model 2 — 2026-10-31

Model 1 retains the original scheduler, Hann/Tukey choice, fixed overlap gain and RNG draw order. Model 2 is selected by the saved `ModelVersions.cloud` metadata; old states without it select 1. Density/Size parameter values and their registry defaults (20 grains/s, 60 ms) do not change.

Model 2 uses stratified ±5% onset jitter (still consumes the same one onset random draw), Tukey windows at every size, and instantaneous squared-window/amp overlap normalization. Its gain `0.5 / sqrt(max(0.0625, energy))` is bounded at 2, keeps silence silent, and accounts for equal-power stereo panning without adjusting the source signal. Size, position, pitch, pan and amplitude random draws retain their old distributions. This reduces holes caused by the legacy ±50% scheduler and Hann edges without secretly increasing grain density or length. Processing remains bounded by 48 grains, no allocation, no locks, no extra history reads.

Native Linux x86_64 GCC Release probe, pinned JUCE8.0.15 modules reused (no module rebuild): two new component tests pass. Mean 10ms stereo RMS envelope coefficient of variation over 20 seeds on deterministic stereo white-noise history: model1 0.560414, model2 0.087475 at registry defaults. Both versions are deterministic, finite, bounded in grain count and allocation-free. Independent original-source comparison compiled `CloudMode` from commit1432394 alongside current model1 and compared 1,920,000 float samples exactly across20seeds, pitch100/600, density20/80, size60/250 and chaos0.3: identical.

The production FillVoice default-setting assertion now requires ≥20% reduction versus plain Granular at registry defaults, replacing the former dense-only assertion. That assertion, the canonical drum-loop fixture, whole-plugin state routing, cross-platform native results and listening review still require integrated candidate validation. Component window-modulation results alone are not the final acceptance metric.
