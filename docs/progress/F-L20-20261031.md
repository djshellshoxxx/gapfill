# F-L20 per-voice formant implementation, 2026-10-31

The independent six-parameter `fl20_*` path is implemented beside the unchanged
`fmt*` bus card. Group registration appends global host indices 216–221.
The engine snapshots settings, honors per-band effect exclusions, and owns
two processors shared by natural fills and recipe previews. Short gaps and
pool exhaustion play unprocessed with separate counters. No recipe bits or
state subtree are repurposed. Random leaves the new controls alone; normal
Undo/A-B and state persistence retain them.

The private stereo transform packs two independent real signals into one
complex FFT, and similarly pairs their real-even log-spectrum cepstral
transforms. This is algebraically equivalent to the per-channel estimator;
it does not link the stereo envelopes or change either phase. Prepared
vowel/tilt/warp tables avoid repeating fixed calculations on every frame.
Frame energy matching weights DC/Nyquist once and other bins twice, as
required by Parseval for a half spectrum.

N is 512/1024/2048 at up-to-48/up-to-96/up-to-192 kHz. The private STFT and
one extra output sample give exact N delay. Source input stops N samples
before the planned output deadline; final fade, duck and panic remain after
the stage. No plugin latency/PDC is changed. The detailed specification's
instruction to prime the first N source samples conflicts with its required
N-sample onset delay; this implementation retains the measurable delay and
drains inside the original deadline. Help explains the onset and fallback.

Pool lifetime encloses all engine voices. Ending, reset, re-prepare and
destruction release voice claims; the pool is declared before voices so it
outlives their destructors. Allocation/plans remain in prepare, and audio
ownership remains exclusive. Standard hold-performance voices keep their
existing independent effect policy.

## Native component evidence

The feature's production DSP was compiled with GCC C++20 Release against
the already-built pinned JUCE 8.0.15 module objects. A component runner links
`TestFormant.cpp` and the unchanged `TestSpectral.cpp`; it deliberately does
not link incompatible old processor/cache objects for production integration.

The final native run used `GAPFILL_PERF_ENFORCE=1`: **21 passed, 0 failed**
(10 Formant component cases, one Perf case and 10 existing SP-0 cases).

- Identity reconstruction: below the test's -80 dB error threshold at
  44.1/48/96/192 kHz with exact N onset delay.
- Shift +7: fundamental errors +0.0330/+0.0248/+0.0345/-0.0614 cents;
  centroid ratios 1.16438/1.19390/1.20353/1.19220, all inside the specified
  30–60 percent of the expected shift-factor increase.
- Non-neutral click (Shift +7, vowel A, Preserve 0): peak at N within one
  sample and pre-echo below -35 dB at all four rates. A spectrally flat
  impulse frame is intentionally left intact to avoid pre-ringing.
- Pink-noise extremes: all 24 rate/vowel cases within 1.5 dB; worst absolute
  deviation 0.545 dB at 48 kHz, vowel O. The first implementation failed
  at -1.842 dB; correcting half-spectrum energy weights fixed it without
  changing the criterion.
- All five vowels' first two resonance peaks within 10 percent of the
  prescribed frequencies; independent-channel/DC, opposite-phase stereo,
  deterministic extreme controls, finite recovery and silence tests pass.
- Claimed two-processor pool, short/busy fallbacks and audio allocation
  guards pass, including 192 kHz processing.
- Worst-control two-instance benchmark (48 kHz, stereo, Amount 100,
  Shift +12, Tilt +6, vowel E, Preserve 50, Detail High): **2.7806 percent
  of one core**, measured by process CPU clock over one second of audio.
  The enforced budget is 3 percent. The initial unoptimized implementation
  used approximately 9.9 percent; FFT pairing/caching and moving redundant
  per-sample denormal guards to frame scope reduced it. The host already
  guards the complete audio callback.

The source passes strict GCC syntax checks (`-Wall -Wextra -Wconversion
-Wshadow -Werror`, JUCE headers treated as system headers). Preflight reports
222 stable IDs, and the completeness audit reports zero failures with the
same eight pre-existing exemptions.

## Acceptance still requiring integrated or external evidence

The separate `TestFormantIntegration.cpp` cases cover actual parameter and
state round trips, legacy-off bit identity/no claims, positive natural-fill
production wiring without PDC changes, panic/deadline behavior and claim
release on prepare/destruction. They pass syntax compilation but require
the coordinator's new integrated native build before any runtime pass claim.

Native Windows/macOS format checks, whole-plugin sanitizers, physical host
automation, listening, and UI screenshots/keyboard/screen-reader review
remain unverified. The compact FORMANT disclosure uses the established
CreativeExtra SHAPE-style popover because that slot is a header row; visual
approval of this placement is required. The original SP-0 implementation
and callback API remain unchanged; an unused optimization prototype was
removed rather than adding an unneeded shared abstraction.
