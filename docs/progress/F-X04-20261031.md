## Behavior and compatibility

Old projects retain model1 through the shared `CreativeModels` metadata adapter.
The C++ tracker and settings defaults remain1. New model2 is an explicit selection,
never a changed released parameter choice/range or reused recipe bit. Core module
contracts and bounded assumptions are in `Source/features/arrangement/README.md`.

Two v1 defects are corrected only in v2. Historical min/max coordinates made a
new maximum compare equal to a former maximum; v2 uses the current normalization
range for both observations in each new SSM row. Boundary peaks identify the
last pre-change frame; v2 reports its following edge and forecasts repeated
periods through the known detection delay. A missing confirmation expires after
seven frames; arbitrary future structure is not forecast. Invalid transport has
no snapped forecast. Absolute quarter-note PPQ supports fractional signatures,
negative pre-roll and bar/phrase alignment.

V2 Calm multiplies `perf.probabilityMul`, already consumed by the scheduler's
ordinary probability roll, instead of relying on Density's0.4 probability floor.
It adds no RNG draws and does not force a fill or alter protection. V1's mapping
is unchanged. Learning/confidence gates stay neutral.
