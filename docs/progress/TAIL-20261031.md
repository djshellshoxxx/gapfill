# Conservative host tail prediction —2026-10-31

`Source/features/tail/TailPrediction.h` is ready for the root getter adapter.
No PluginProcessor/FxChain hot files were changed. AllFXoff is exactly the
released2.5s. Active old serial cards add complete prepared extents, including
completion fade/chunk overshoot and spectral support. Active new parallel returns
contribute their maximum extent once. This over-bounds parallel sends before or
after the serial chain and cannot truncate a valid old cascade by taking max.

API: `tail::PublishedBounds published;` constructor initializes conservative
pre-prepare defaults. After preparing cards, fill `PreparedBounds::legacySeconds`
in enum order Formant/Resonator/Shift/Dub/Convolution/Freeze and call publish().
At getTailLengthSeconds, create `Activation` from raw parameter atomics using the
same enabled/mode rules as DSP (even before the first callback), set the largest
new parallel return bound, then return `predictSeconds(published.load(),active)`.
Never call `card.isIdle()` from this host/background thread. A failed publish
is a configuration error, and the host receives a finite conservative fallback.

All six prepared bounds publish as one atomic64-bit word; upward1/16s rounding
adds less62.5ms per active card. It changes only how long a host may render
silence; no sample or dry/PDC latency changes. Actual quality caps need not be
read from mutable audio state: Full upper bounds safely cover smaller tiers.
The default8s Dub and configured16s Dub are both represented. Raw amount changes
are read at the host query, so automation before the first callback is accounted.

16s-cap/rate rounding, true serial cascades, maximum of parallel returns,
four supported rates plus8k floor, invalid data and coherent concurrent20,000
