## Root integration API

- `PitchMarks::prepare(sr)` once off audio; `find(Capture,f0)` is bounded, allocation-
  free and returns `{epochs,failure,ready()}`. One central scratch is sufficient.
- `Capture{left,right,length,channels}` borrows immutable captured PCM; channels
  means actual source input channels, independent of a stereo wet/render bus.
- `Voice::configure(Setup,Capture,EpochTable,sr,recipeSeed32,plannedSamples)` latches
  the new controls, copied marks and bounded state. False means use plain Granular.
- `Voice::render(l,r)` adds UNWEIGHTED PSOLA; `active/voices/activeGrains/reset` are
  audio-owner methods. `Voice::mixWeight()` exposes latched internal mix01 for
  root's plainGranular*(1-mix)+PSOLA*mix blend. Skip epoch/configure work atmix0.
- PSOLA selection/base/fallback bypasses old harmonic/cloud render-mode branches;
  explicit old recipe replays with absent sidecars retain their old dispatch.
- Used metadata records actual selected voices only after successful configure;
  a failed configure reports EpochFallback with the valid requested voice count
  (the inactive Voice getter returns0). Do not fabricate Unvoiced when FX send0
  merely skips processing; retain any incoming recorded choice.
- Keep captured storage alive until voice reset/end; reset invalidates all borrowed
  pointers. Apply the existing voice envelope/duck/panic/fades after the new stage.

The approved adaptive-window correction is documented in the tracker/extension
contract records. It preserves rate1 reads and pitch-synchronous source centers;
no resampling substitute or relaxed pitch metric is used.
